## 1. Purpose & Scope

This application is developed as an **academic portfolio project** for a 2nd-year B.Tech Computer Science semester assessment. It demonstrates proficiency in full-stack development, machine learning, and system design.

**This system is NOT:**
- A certified medical device (FDA, CE, or equivalent)
- A replacement for professional medical advice
- Suitable for clinical decision-making
- Validated for real-world patient use

## 3. Data Ethics

### 3.1 Datasets Used

| Dataset | Source | License | Notes |
|---------|--------|---------|-------|
| UCI ML Repository datasets | University of California, Irvine | CC BY 4.0 | Heart, Liver, Kidney, Breast Cancer |
| Kaggle Disease Symptom Dataset | Kaggle (public) | Open data | General disease prediction |
| Chest X-Ray Images | Kaggle | CC BY 4.0 | Pneumonia detection |
| HAM10000 | Harvard Dataverse | CC BY-NC-SA 4.0 | Skin lesion classification |
| Mental Health (Synthetic) | Self-generated | N/A | Synthetic data with documented distributions |
| Severity (Synthetic) | Self-generated | N/A | Synthetic data for academic demo |

### 3.2 No Real Patient Data
- All datasets are publicly available and de-identified
- No Protected Health Information (PHI) is used
- No real patient data is collected, stored, or processed
- Synthetic datasets are clearly labeled

### 3.3 Data Minimization
- Only essential features are collected for each prediction
- No personally identifiable information beyond email and name
- Prediction history can be deleted by the user (GDPR-style)

## 4. Bias & Fairness

### 4.1 Known Limitations

| Model | Known Bias | Mitigation |
|-------|-----------|------------|
| General Disease | Training data skewed toward common Western diseases | Documented in model metrics |
| Diabetes | Pima Indian dataset — specific to one population | Feature names clarified; limitation noted |
| Heart Disease | Cleveland dataset — mostly male patients (67%) | Gender distribution disclosed |
| Breast Cancer | Wisconsin dataset — high accuracy but limited diversity | Confusion matrix provided |
| Pneumonia CNN | Pediatric X-rays predominantly | Transfer learning with data augmentation |
| Mental Health | Synthetic — no real clinical validation | Labeled "academic purposes only" |

### 4.2 Transparency
- Model accuracy, precision, recall, and F1 scores are computed and stored in `ml/artifacts/<model>_metrics.json`
- Confusion matrix visualizations are auto-generated during training
- Confidence scores are always shown alongside predictions
- Top-K predictions (not just the top one) are returned to show model uncertainty

## 5. Privacy & Security

### 5.1 Authentication
- Passwords are hashed with bcrypt (never stored in plaintext)
- JWT tokens expire after 15 minutes (access) / 7 days (refresh)
- Rate limiting prevents brute-force attacks

### 5.2 GDPR Compliance Features
- **Right to Deletion**: `DELETE /api/auth/me` removes user account and all prediction history
- **Data Portability**: Prediction history is accessible via API
- **Consent**: Guest mode requires no personal data at all

### 5.3 Security Measures
- Global exception handler prevents stack trace leakage
- Input validation on all endpoints (Pydantic v2)
- CORS restricted to frontend origin
- File upload limits (5MB, image types only)
- SQL injection prevention (SQLAlchemy ORM)

---

## 6. Responsible Deployment

### 6.1 Risk Mitigation
- Application clearly labeled as "academic project"
- No deployment to production healthcare environments
- No integration with EHR/EMR systems
- Guest mode prevents unauthorized data collection

### 6.2 Human Oversight
- All predictions include a "consult a doctor" recommendation
- Severity scores above 7.0 trigger "seek immediate help" warnings
- Red flag symptoms are prominently highlighted in Disease Library
- Chatbot explicitly states it cannot provide medical advice

## 7. Environmental Impact

- **CPU-only inference**: No GPU required, reducing energy consumption
- **Lightweight models**: MobileNetV2 (~14MB) instead of large vision models
- **SQLite**: No separate database server required for development
- **< 2GB total size**: Minimal storage footprint
